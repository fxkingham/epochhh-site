📋 About The Project

EPOCH is a custom-built photography portfolio designed to showcase original photography and digital artwork with a clean, modern aesthetic.

The site was developed using vanilla HTML, CSS, and JavaScript, with GitHub Pages for hosting and Cloudflare for performance and security.
